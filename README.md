# Holiday Activity Planner

Codingal after-class project — lesson: **Nested Conditional Statements**.

A small Python program that asks for a holiday type (Beach or Mountain), then asks a second question based on the first answer and prints a personalised activity plan.

## How to run

```
python holiday_planner.py
```

## How it works

- Outer decision (`if` / `elif` / `else`): Beach Holiday, Mountain Holiday, or invalid choice.
- Inner decision (nested `if` / `else`): Swimming or Sandcastle Building for the beach; Hiking or Camping for the mountain.
